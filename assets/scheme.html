The agent and the environment

Companion scheme for “Agents don't need long-term memory. They need an environment.” The environment is the part of the world that survives reasoning. The test is erasure: memory can be wiped without losing a single fact about the world; the environment cannot.

  • Memory is rewritten directly — it belongs to the agent
  • The environment changes only through work — there is no “update my long-term memory”
  • The gate belongs to the environment — one law for humans and agents alike

③ Validation gate

Guards the write path of derived artifacts, human and agent alike. Top-level rules are shared; concrete checks differ: review and approval for people, deterministic pipelines for agents.

The asymmetry is held by infrastructure, not by the model's discipline: working memory is rewritten directly; the environment changes only through actions that pass its own rules. Whatever fails the gate remains working memory and dies with it.
